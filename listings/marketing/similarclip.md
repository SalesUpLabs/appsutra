**About**

SimilarClip runs an automated YouTube channel. Pick a niche or a topic, choose one of 11 visual styles and one of 35 natural voices, connect a YouTube channel and set a publishing cadence. SimilarClip researches the topic, writes the script, breaks it into scenes, generates the visuals and narration, and publishes each video on schedule.

No camera, editing or source footage is required, and every script, visual and voiceover is generated fresh. An MCP server and a REST API let an agent generate and publish videos with a single API key.

**Key Features**

- Automatic research, scriptwriting, illustration and narration
- 11 visual styles and 35 natural voices
- Publishing to a connected YouTube channel on a schedule
- MCP server and REST API with one bearer key
- No camera, editing or source footage needed

**Pricing**

- Pro: $99/month (about 55 video minutes, 3 channels)
